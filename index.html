Private Drive Storage

A private personal tool for saving the owner's own monitoring data in the owner's own Google Drive.

The tool uses Google OAuth to obtain the owner's permission to create, read and update its files. Its only Google API scope is https://www.googleapis.com/auth/drive.file. Access is limited to files created by the tool and files or folders explicitly selected by the owner.

This public site contains only a description and policies. It does not expose monitoring data, application source code or credentials. It has no analytics, tracking scripts, forms or advertising.

Read the privacy policy and terms of use.
